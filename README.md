# Aurum Sinuca — versão jogável 1.0

Aplicação de teste online, sem dinheiro real.

## Incluído
- mesa 2D jogável com mouse/toque;
- treino grátis sem ranking/premiação;
- amistoso online 1x1 por sala/código, sincronizado via Socket.IO;
- cadastro de jogadores;
- ranking de amistosos;
- campeonatos 8/16/32/64/128 com chave, BYE e repescagem;
- dinheiro, carteira, apostas, PIX e pagamentos desativados.

## Rodar
Node.js 20+: `npm install` e `npm start`.
